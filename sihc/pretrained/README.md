# Checkpoints and evaluation assets

Large weights are hosted on Hugging Face; this directory contains metadata only.

- [Checkpoint catalog](checkpoints.json): exact repositories, revisions, architecture identities and available states.
- [Evaluation assets](assets.json): pinned JiT ImageNet-256 reference statistics.
- [Evaluation guide](../evaluation/README.md): download and evaluate the paper SiHC-XL + REPA checkpoint.

The topic subdirectories preserve HF catalog snapshots, including historical runs. Their checkpoint links go to HF. Consult the top-level catalog for the selected paper checkpoint; the owner's earlier epoch-400/480 copies are separate from the coauthor's step-650520 checkpoint.
