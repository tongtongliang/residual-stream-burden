# Research diagnostics

The [toy suite](toy/README.md) is independent of image-model training and
evaluation. It includes synthetic data, two compact residual architectures,
matched clean/velocity/noise objectives, and executable diagnostics for spectra,
conditional noise and gradient paths. It uses local files and NumPy/PyTorch.

Historical experiment logs, paper drafts, executed notebooks, image assets and
private checkpoint registries are not needed by this code and are not included.
Toy metrics describe the toy construction; they are not reported ImageNet results.
