# Per-Mode Patch SNR

Noisy input \(z_q=(1-q)x+q\varepsilon\) in the clean \(\mathrm{Cov}(x)\) eigenbasis:

$$\mathrm{SNR}_i(q)=\frac{(1-q)^2\lambda_i}{q^2}.$$

A direction is **clear** when \(\mathrm{SNR}_i\ge 1\) (also reported at 0.1 and 10).
Clean eigenvalues: `outputs/eigenvalues.csv.gz`, `object=noisy_input`, `q=0`.
